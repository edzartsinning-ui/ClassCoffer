# ClassCoffer Website

Statische Website mit lokalem CSS und JavaScript, ohne externe Bibliotheken, Schriftarten, Tracking oder Cookies. `index.html` im Browser öffnen. Alle Dateien dieses Ordners gemeinsam auf den Webserver oder in ein GitHub-Pages-Repository kopieren.

Enthalten: Startseite, Anleitung, Support, Datenschutz, Impressum in Deutsch, Englisch, Französisch, Spanisch, Italienisch und Niederländisch. Die Sprache wird aus der Browserpräferenz ermittelt und kann in der Kopfzeile dauerhaft umgestellt werden. Ohne JavaScript bleiben alle Seiten und Sprachversionen direkt aufrufbar.

Der Schwerpunkt liegt auf Buchhaltung, Kontoständen und Übersicht über Klassenkonten. Die Produktansicht verwendet ausschließlich den bereitgestellten App-Screenshot. Das Logo ist das originale App-Icon aus dem Xcode-Projekt. Die Website ist kein Buchhaltungssystem und verarbeitet keine Kontodaten.

Vor der Veröffentlichung die Datenschutzangaben zum tatsächlich eingesetzten Hostinganbieter vervollständigen. Eine endgültige Domain und ein App-Store-Link wurden nicht erfunden. Sobald die App gelistet ist, kann der echte App-Store-Link ergänzt werden. Anbieteranschrift und Supportkontakt wurden aus der vorhandenen Sitzplan-Website übernommen.
