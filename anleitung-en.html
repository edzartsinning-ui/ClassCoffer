Create a class and account

Import students from Excel, CSV or pasted data. Create class accounts and set a target contribution if needed.

Import student lists

Copy the table with headers if possible. First name, last name and class are detected automatically; adjust the mapping below.

Each student is assigned to their source class. Missing classes are created. Empty class fields use the selected target class.

No clear headers found. Check the columns; the first data row is retained.

Record transactions

Enter amount, date and subject. Allocate the transaction to students or keep it as a general account amount.

The entered amount is the total, not the amount per student. It is split to the cent among assigned students. The selection is saved with the transaction.

One payment for a school trip and class fund can be split across activities. The parts must add up to the total payment.

See outstanding contributions

Per student: payments received, allocated expenses and remaining credit. Bold payment totals mean the target is reached; ! means it is exceeded.

Correct and reverse

Reversed transaction: amount and allocation stay locked. Date, text and notes can be edited.

Reverse transaction? The original is retained and offset by a reversing entry.

Review and export

Find CSV and PDF statements in transactions and individual student statements. Income and expense totals exclude reversed entries and their reversals. History and exports include the complete record.

Create PDF and CSV statements for accounts and students. Export all personal statements for one activity together as a ZIP.

Back up and change devices

No account, server or automatic cloud sync. Changes are saved locally immediately; the previous state is kept as previous.json in the app’s data folder. To change devices, export a JSON backup and import it on the other device.

Import adds to existing records. Identical IDs are skipped. Different content with the same ID stops the entire import; existing data is not overwritten.

The local working file has no additional app-password encryption. Password protection applies to explicitly encrypted exports. Protect the device with a passcode or FileVault.

At least 10 characters. AES-256-GCM, PBKDF2-SHA256 with 600,000 rounds and random salt. Keychain storage is optional.

Language

Use “Language” in the sidebar. Choose the system language or German, English, French, Spanish, Italian or Dutch. Your choice is saved.
